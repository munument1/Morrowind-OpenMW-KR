# OpenMW-KR 전체 대화 기능 확장 감사 (2026-11-04)

**상태: 로컬 실물 정적 검사 수행 / 후보 의미 검수·실게임 진행 시험 미완료 / 신규 릴리스 금지**

사용자 지적대로 가입·승진 이외 인사말, 일반 토픽, 퀘스트 단서, 선택지, 스크립트 토픽 추가, 아이템, 동료 조작, 일지 ID, NPC 필터까지 검사 범위를 넓힘. 영문 원본과 **현재 실제 Nexus/GitHub 공개 한국어판**, Rebirth 호환 ESM 재생성본으로 대조했다. 영어 원본/한국어판은 수정하지 않았다.

## 범위

기존 [실물 원본 전수검사](2026-11-04_full_source_binary_topic_audit.md)에서 17개 플러그인의 INFO **160,932건**(본편 31,716, 지역/PFP/Rebirth 108,955, Rebirth-Cyr/Sky 호환판 20,261)을 순회하고, 명시 토픽 링크 **17,120개**가 검사 대상 전체 DIAL/TOP 집합에서 목표를 갖는지 확인. 7개 대표 설치 구성의 TOP 키 상충 0. 주의: 대체/호환판 중복 포함, 전체 로드아웃/게임 진행 무오류 보증 아님.

이번에는 스크립트 `INFO.BNAM`/`SCPT.SCTX`에서 *출력되는 한국어 문장* 이외의 실제 명령·분기도 검사했다.

| 원문↔한국어 스크립트 검사 | 전체 | 원본 대비 차이 |
|---|---:|---|
| `Choice` | 14,295 | 숫자 분기 인덱스 변경 0 |
| `AddTopic` | 12,032 | 추가 명령 수 일치 |
| `Journal`/`GetJournalIndex`/`SetJournalIndex` | 19,276 | 퀘스트 ID 변경 0 |

`AddTopic`에서 **한국어 토픽명으로 바뀐 111회**를 실제 대상 DIAL에 대조했다. **101회는 같은 한국어 플러그인, 10회는 다른 검사 대상 플러그인의 DIAL**이 존재했고 전체 집합에서 대상 없는 경우는 0. 다만 나중에 로드되는 모드가 반드시 활성화되는지 별도 검사 필요.

1차 `Choice` 5개 구조 경고 중 TR_Mainland 4개는 영문 원본의 쉼표(`", 1, "...", 2`)를 파서가 처리하지 못한 **오탐**. 본편 1개는 오히려 *영문 원본*의 잘못된 `Choice "Give her the land deed' 1`을 한국어판에서 정상 따옴표로 고친 사례. 별도 V2 검사는 현재 한국어 `Choice`에서 비인용 명령 5건을 검출했으나 원문도 동일하므로 **번역 때문에 생긴 선택지 파손은 확인되지 않음**.

## 가입/승진 외의 퀘스트 진입 후보

원문에서 토픽으로 인식 가능한 언급 ↔ 한국어 검색어·대사 표시 불일치를 전체 대사에서 비교하고, 대상 DIAL/INFO의 NPC `ONAM`, `FNAM` 및 실행 스크립트를 결합했다.

- 스크립트가 연결된 것으로 보이는 **정적 검토 후보 16,725회**: 이 중 가입·승진 이외 **16,397회** (호환/대체 플러그인 중복 포함)
- 기능별 후보 태그 (중복 집계): `Journal` 5,290, `Choice` 4,837, `AddTopic` 11,971, 아이템 2,823, NPC 명령 2,476, 팩션 377, 퀘스트 변수 4,688
- **이 수치는 확정 버그나 퀘스트 차단 수가 아니다.** 영어의 일반 단어도 엔진 토픽 검색 후보가 될 수 있고, 해당 DIAL에서의 모든 다른 INFO 스크립트가 실제 같은 NPC·게임 단계에서 실행되는 것은 아님. 반드시 개별 동적 접근성·원문 실게임 링크를 검증한 후에만 수정할 것.
