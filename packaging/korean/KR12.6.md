# OpenMW 한국어 KR12.6 — 명시 토픽 링크 범위 정적 교정

2026-11-02. KR12.5 **공식 통합 ZIP**을 기준으로 작업한 Windows x64 누적 데이터 수정판입니다.

## 변경 범위

- 대사 `INFO.NAME` **230개 필드**에서 단어 중간에서 시작하던 명시 링크 **256개**의 클릭 범위를 재정렬했습니다.
- 기존 토픽 목표 ID를 그대로 유지하기 위해 `.top`에 고유한 별표 구분 별칭 **86개**를 추가했습니다. 구분용 `0x7F` 문자는 화면 표시에서 제거되는 엔진 규칙을 이용하며, 본편 기존 TOP 5,848개의 매핑 및 파일 순서는 그대로 유지했습니다.
- 화면에 표시되는 한국어 문장, DIAL/INFO ID 및 체인, 조건, 스크립트, 다른 ESM/ESP 필드는 수정하지 않았습니다.
- 변경 위치를 안전하게 확정하지 못한 **48개 링크 후보는 보류**했습니다. 이전 제보 #42의 모든 219줄/51토픽 문제를 해결했다는 의미가 아닙니다.

- `esmtool` 파싱, ZIP CRC, 새 패키지의 비대상 멤버 내용 불변 PASS.

- **NPC·퀘스트 상태별 실제 토픽 습득 및 실게임 플레이는 검증하지 않았습니다.** 암묵적 링크의 모든 오연결과 제보 #42가 완전히 해결됐다고 주장하지 않습니다.
