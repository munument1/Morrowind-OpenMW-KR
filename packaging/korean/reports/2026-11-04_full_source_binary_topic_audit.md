## 2. 명시 링크 `@...#` 전수검사

모든 160,932 INFO에서 **명시 링크 토큰 17,120개**를 추출했다.

| 해석 경로 | 링크 |
|---|---:|
| 해당 플러그인의 TOP 별칭으로 연결 | 16,052 |
| 해당 플러그인의 DIAL에 직접 연결 | 182 |
| 외부 모드/본편 DIAL로 연결 | 384 |
| 다른 모드의 TOP 별칭으로 연결되는 대상 존재 | 488 |
| 외부 DIAL 표시명으로 직접 연결 | 14 |
| **현재 검사한 전체 DIAL/TOP 집합에서 대상 불명** | **0** |

이것은 **검사 대상 전체의 유니온에서 유효한 목표가 존재한다**는 뜻이다. 일부 링크의 외부 모드가 실제로 활성화되지 않거나 NPC가 토픽을 모르는 상태에서는 클릭이 불가능할 수 있다. 런타임 토픽 습득·선택 상태는 테스트하지 않았다.

상용 원본/한글본을 함께 로드한다고 가정한 **7개 대표적 설치 조합**(본편+PFP, 본편+TR, 본편+Cyrodiil, 본편+Skyrim, 본편+Rebirth, Rebirth+Cyrodiil 호환, Rebirth+Skyrim 호환)에서 **동일한 TOP 키가 서로 다른 목표로 지정되는 충돌 0건**을 확인했다. OpenMW의 플러그인별 TOP 이름공간 자체는 실행 검증하지 않았으므로 최종 게임 QA와 동일시하지 않는다.

## 3. 한국어 자동 토픽 인식 문제: 전수 후보 → 정밀 확인

첫 문자열 기반 스캔은 **영어 일반 단어가 토픽 ID와 같은 경우까지 포함**한다. 따라서 후보 총량을 오류 건수로 표현하지 않는다.

- 14개 공개 모드 플러그인에서 영어 토픽 152,322개 언급/연결 추정. 2차 스캔에서 실제 한글 검색어(MRK, 한글 DIAL 또는 본편 연결)가 없는 항목은 **미검증 보류**로 분리했다.
- 본편 KR12.7: 원본 3종 영어 INFO+조건 전수 대조, 사용자 표시 문장에서 소실 가능 토픽도 전체 분석.
- 별도 Rebirth 호환 2종: 공개 지역 모드와 서로 반복하는 대사가 상당수이므로 겹침을 구분한다.
- 파서 수동·네이티브 비교 및 퀘스트 입구 키워드 조건으로 우선 검토할 **341개 연결 후보**로 범위 축소:
  - 가입 질문 168
  - 가입 언급 일반 대사 90
  - 승진·임무 등 65
  - 자기 토픽 재언급/한글 키워드 미매핑 18
- 실제 **동일 NPC·파벌·대상 INFO/스크립트 교차검사**:
  - **103건:** 대상 INFO에 해당 NPC/파벌 또는 일반 응답 가능성이 있고 `PCJoinFaction` 또는 `Choice` 스크립트 있음
  - **125건:** 해당 NPC/파벌 또는 일반 응답 가능 대상 INFO 존재, 직접 가입/선택 스크립트는 미확정
  - **113건:** 대상 DIAL 자체는 있지만 그 NPC의 이용 가능한 경로는 아직 입증되지 않음

위 341건 및 103건은 **고유 확정 버그 수가 아니다.** 예: 기존 토픽을 재언급하거나 원문 `join us`가 "그에게 우리 조직 가입을 권했느냐"라는 일반적 질문에 등장하는 경우, 클릭이 실제 진행에 필요하지 않을 수 있다. Rebirth 호환 대사가 지역 본편과 중복된 것도 있다. `SCVR` 및 Player Journal/Save, `AddTopic`와 대사 순서/조건을 구현하는 런타임은 여기에 포함되지 않았다.

## 4. 바이너리 및 스크립트 구조 안전성

- 14개 현재 Nexus 번역 플러그인과 사용자가 다운로드한 해당 버전의 원본 ESP/ESM 레코드 수/순서 일치.
- 전체 비교에서 변경된 필드 181,516건. 달라진 스크립트 SCTX/INFO.BNAM 8,054개는 따옴표 안 표시 문자열 변경 8,053개 및 주석 차이 1개로 설명. 정규화된 실행 스크립트 본문 실질 변경 확인되지 않음.
- 본편 KR12.7에서 영어 원본 INFO 3종과 번역판의 ID/핵심 선택조건 바이트가 일치하는 원본 후보 존재. 대부분 DIAL도 확정 대응; 중복·불확실 DIAL 관계는 별도 보류.
- 이는 링크 누락이 없음을 뜻하지 않고, **그 누락이 주로 표시 문장·한국어 검색어에 있다는 근거**이다.

## 5. 릴리스 상태 / 차단 게이트

**현재 정식 전체 재검수판 릴리스: 없음.**

- 기존 자동 워크플로가 GitHub **KR12.7**을 먼저 게시함. 이 릴리스는 검수 완료판이 아니라 **본편 INFO 5개 수정 핫픽스**이다. 수정 ESP 자체는 SHA·구조 검증했으나 전체 토픽 검사보다 앞서 공개되었으므로 최종판이라는 표현 금지.
- KR12.7 자동 push 릴리스 트리거는 제거하여 추가 자동 배포 방지.
- 지역 모드 9개 시험 패키지는 **Nexus에 게시하지 않음**.
- 341개 후보 가운데 가입/선택 실제 동작과 관련된 103개부터 원문·한국어·NPC/저널 조건·마지막 로드 플러그인을 대조하고, 꼭 필요한 명시 링크만 수정할 것.
- 수정한 ESP/ESM은 동일 원본 해시/레코드 수 및 INFO/SCVR/퀘스트 스크립트 불변, 실제 OpenMW 한국어 파서 테스트, TOP 별칭 충돌 0, 저널 상태/로드 순서 회귀를 통과해야 릴리스.
- **게임 내 퀘스트·세이브 기반 테스트와 위 후보의 개별 의미 판단이 완료되지 않은 상태에서 전수검증 PASS를 선포하지 말 것.**
