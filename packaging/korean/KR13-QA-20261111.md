# OpenMW KR13 / 지역 확장 모드 검증 기록 (2026-11-11)

> KR13 기술 검증 기록이다. 아래 델타 패키지 검사는 이전 포장 방식의 이력이며,
> 현재 모드 정식 배포 방식은 전체 ESM/ESP 덮어쓰기다. 최신 설치 지침은 `docs/NEXUS_RELEASE.md`를 따른다.

## 지역 모드 포장 교정

kr0.4.1(Sky kr0.3.1)은 전체 번역 ESM/ESP 덮어쓰기 ZIP이다. 검증된 KR13의 플러그인 7개와
사이드카 24개를 공개 델타의 최종 생성 결과와 바이트 단위로 대조했다. 모두 같으며 게임 데이터
변경은 없다. ZIP에는 전체 플러그인·사이드카·설치 안내·해시 매니페스트가 들어간다.
델타 전용 ZIP과 누락된 플러그인/사이드카, 변조된 해시, 불필요한 적용기 혼입을 거부하는 검사와
5개 Nexus 대상·업로드 경계를 검사하는 회귀 테스트 10개가 통과했다. 엔진 소스 변경은 없다.

## 범위와 결과

- 이슈 [#63](https://github.com/munument1/Morrowind-OpenMW-KR/issues/63): 지역 모드 영어 표시 후보 **4,187건 전수 분류**. 그중 SHA·원본 문맥이 확인된 **1,033개** 표시 원문을 번역하고 별도 `FACT.RNAM` 계급명 **778건**을 보정해 총 **1,811개 표시 필드**가 변경됨. 4,187건 모두를 번역했다는 뜻이 아님.
- 이슈 [#66](https://github.com/munument1/Morrowind-OpenMW-KR/issues/66): 영어 토픽 식별자/한국어 표시 별칭/기본 NPC에서 지역 신규 NPC로 전달되는 주제 확인. 기존 영어 대화 기록도 보존하도록 코어 ESP·TOP과 OpenMW 0.51.0 (`0017` 패치까지)를 함께 묶음.
- 토픽 검사: 기본/지역/PFP/Rebirth 12개 로드 구성 × discovery/display = **24 네이티브 모드 전부 PASS**, `unreviewed_losses=[]`, PFP 포함. 검수된 토픽 손실 0. 2026-11-11 격리 복사본에서 동일 보고 SHA256 `c0ebde2b148eb3e6f1cbbb5136fb7c192c1593f2d4d3afd580e624609783c01a` 재생성.
- Python 회귀: 2026-11-11 기준 지역/책/토픽/의미/모드/코어 KR13 패키지/델타 적용 **전체 65건 중 64 PASS, 1 SKIP** (Windows symlink 생성 권한 제한; 모의 symlink 차단 테스트는 PASS). `git diff --check` PASS.

## 격리 실게임 OpenMW 0.51 GUI 확인

- KR13 Windows **실제 설치기**를 사용자 게임이 아닌 가상 폴더에 설치하고 `openmw.exe` + `resources/version` + 번역 ESP/TOP의 해시/백업을 확인. 검증된 엔진 SHA256 `c94e4fe63d59220cb8151c8bdf1449743ea4531731ff7ed1fe1a149cac7cd312`.
- 기본 NPC `훌`: `AddTopic` 없이 자연 습득된 `내 직업` 클릭 → 한국어 응답 **PASS**.
- 표준 TR/TD/Cyr/Sky/TR_Factions: 기존 자연 획득 테스트 저장을 **원본 수정 없이 복사**한 다음 지역 NPC `나렌 랄람`의 `작은 비밀` 및 `내 직업`을 클릭 → 한국어 응답 **PASS**.
- Rebirth 7.2: 일반 Cyr/Sky를 끄고 전용 Cyrodiil/Skyrim 대체 ESM과 Rebirth 메인·Addon, TR/TD를 포함한 **17개 content** 로드. `불꽃눈 에이디스`의 한국어 인사말과 `전사 길드` 응답 **PASS**.
- PFP 5.0.7: 별도 독립 테스트 저장 (`.omwsave`, 226,909 B)을 실제 GUI에서 생성 후 재로드하고 `나렌 랄람`의 `작은 비밀`, `최근 소문`, `배경` 한국어 응답 **PASS**. 생성된 테스트 저장 SHA256 `f2c4d316513ef08de5d2fc30f38b834c49481d50d385aa2f85474258be36dfc7`.
- BOOK198 (`TR_m3_Go_PSI_Signed`) 18페이지, BOOK115 (`TR_m2_445_README`) 장문의 처음/중간/하단 및 기술 식별자 렌더링 확인. 기존 영어 `Background`와 한국어 `배경` 대화 기록 호환 확인.
- 전체 모드의 모든 퀘스트·장소·저장 파일을 끝까지 검수한 것은 아님. 격리 QA에서 일부 TR 원본 모델 에셋이 없어 marker mesh로 대체되었으므로 이를 번역 결함으로 계산하지 않음.

## 원본을 포함하지 않는 지역 패치 대안

- 원본 영문 ESM/ESP **7개를 별도 원저작자 다운로드에서 확인**한 뒤 각각 전체 SHA256을 핀. `bsdiff4`는 **개발자용 패치 생성기**로만 사용. `apply_regional_deltas.py`는 Python 3 표준 라이브러리만으로 BSDIFF40을 적용함.
- 7개 BSDIFF40 패치 총 **12,145,639 B**; 그중 241 MB 원본 TR_Mainland → 255 MB 번역본 패치 **8,159,375 B**. 소스/패치/재구성 결과의 모든 SHA256 확인.
- `--mode all`은 7개 ESM/ESP 재구성 결과 총 **440,868,439 B**를 검증된 KR13 번역본과 byte-identical로 생성. 정상 BSDIFF40의 `0,0,seek` 제어 튜플을 지원하도록 적용기를 교정한 후 실제 데이터로 확인.
- 비공개 지역 패치 ZIP `Morrowind-KR13-Regional-PatchOnly-kr0.4.zip` SHA256 `7f5f1a242f91ac422537598e330465fd1e7f2b6cbc1f92ef2c265da5d0650d92`, 35 ZIP 엔트리 / CRC PASS. **전체 원본 또는 번역 ESM/ESP/BSA/TTF 파일은 ZIP에 없음.** 7개 패치와 24개 EET sidecar(토픽·저널·셀·마커 이름), manifest, 사용법, 적용기만 포함.
- 이 ZIP을 실제 압축 해제한 후 `--mode standard`를 실행해 5개 지역 원본에서 한국어 ESM/ESP를 재구성. 그 출력과 ZIP sidecar를 격리 OpenMW에서 로드, `나렌 랄람` `작은 비밀`·`내 직업` 한국어 응답 **PASS**. 개인 원본/세이브 해시 불변, Fatal/리소스 버전 오류 0.
- 파일을 나란히 생성하는 `--mode all`과 실제 로드 구성은 별개: **일반 Cyr/Sky와 Rebirth 대체 ESM을 동시에 활성화하지 않는다.** 번역용 EET sidecar는 대응 모드의 출력 폴더에 둔다.

## 번역 누락에서 제외된 개발용 데이터

- `Tamriel_Data.esm`의 신문 템플릿 BOOK.TEXT **72건** 및 동일 BOOK.FNAM `<Placeholder>` **72건**은 영문 개발용 자리표시자로 남아 있음. BOOK.FNAM 72건은 최초 4,187 source-candidate 집계의 **별도 미포함 필드**. 강제 생성 후 아이템을 열면 영문이 실제 표시되지만, 분석한 7개 플러그인의 기본 배치/추적/스크립트 조건에서는 자연 접근 가능한 사례를 확인하지 못함. 외부 모드, 콘솔, 기존 저장 데이터까지 불가능하다는 보증은 하지 않음.
- 5개 `<Deprecated>` BOOK 및 기타 내부 마커는 레퍼런스/스크립트 연결이 발견되지 않아 보존. 책 #115와 #198은 **이미 한국어 본문 번역을 적용**했으므로 영문 누락으로 재계산하지 않음.
- `issue63_reviewed_link_exceptions`의 QA 판정 이유에 실렸던 원문 영어 INFO 직접 인용 **39건**을 독립적인 의미 설명으로 변경, 원문 SHA·INFO ID·조건·토픽 링크 결정 불변. 6개 JSON 검사에서 장문의 원문 BOOK.TEXT 전체 복제는 발견되지 않음.

## 현 단계에서 공개하지 않는 이유

1. **지역 ESM 저작권/재배포 조건:** Tamriel Rebuilt, Project Cyrodiil, Skyrim: Home of the Nords, Tamriel Data, Rebirth 원저작자 허락/조건이 확인되지 않은 **전체 번역 ESM/ESP 5개 ZIP을 GitHub/Nexus에 재업로드하지 않는다.** 바이너리 델타 방식이 자동으로 법적 허용을 보장하지도 않으므로 적용 라이선스/허가를 확인해야 함.
2. **KR13 GPL:** OpenMW GPLv3의 대응 소스·패치 0001~0017·빌드 출처/라이선스 고지와 font OFL 고지를 함께 제공해야 함. 비공개 `release-KR13-PUBLIC-STAGING` 후보에는 대응 자료/공지 포함 (65 ZIP 엔트리, CRC/재현성 테스트 PASS), 아직 정식 배포하지 않음.
3. **버전/CI:** `openmw-*` 태그에서 기본 Win/Mac 자동 릴리즈가 KR13 파일과 충돌할 수 있어 `.github/workflows/release.yml`에 KR13 태그 제외 가드를 추가. 해당 변경이 먼저 반영되지 않은 상태로 KR13 태그를 푸시하지 않음.
4. **배포 메타데이터:** 공개될 최종 아카이브/태그/릴리즈 설명/README/Nexus 링크를 실제 배포 버전에 맞추고, 이슈 #63/#66 해결 범위는 검증된 로드 구성으로 한정해야 함.

**결론: 기술 검증은 통과했지만 공식 KR13 및 지역 모드 새 버전 공개, 태그/원격 push, 이슈 종료는 아직 수행하지 않는다.**
