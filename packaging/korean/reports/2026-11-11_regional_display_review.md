# 지역 번역 및 공통 주제 후속 검수

이 작업은 #63과 #66의 후속 수정이다. **진행 중이며 정식 배포나 #63 전체 완료가 아니다.**
기준은 KR12.9, TD/TR/Cyr kr0.3, Sky kr0.2와 Rebirth 지역 교체 ESM이다.
사용자의 설치본과 저장 파일은 수정하지 않았다.

## 현재 교정 범위

- 표시명 89개: 열쇠·표지판·주문·무기·보급 상자. 효과와 엔진 ID는 보존한다.
- 세력 계급 778개: TD의 본편 세력 덮어쓰기로 다시 영어가 되던 계급도 포함한다.
  본편에 있는 계급은 현재 번역을 재사용하고 지역 고유 계급은 원래 순서를 대조했다.
  RNAM은 UTF-8과 종료 NUL을 포함해 정확히 32바이트 이내로 보존한다.
- 대사·일지·책 제목 92개: 화자, 퀘스트 사실, 금액, 방향, 변수와 실제 줄바꿈을 대조했다.
  기존 초안의 고유명사·누락을 그대로 승인하지 않았다.
- 원래 4,187건 후보 중 **854건은 아직 개별 원문 검수가 남아 있다.**
  나머지 제외 판정은 개발용 화자, 편집 마커, 이미지 전용 책, 암호와 데이드릭 글리프 등
  실제 레코드 문맥을 근거로 별도 목록에 기록했다. 제외를 번역 완료로 계산하지 않는다.

통합 TD/TR/Rebirth 구성에서 에이디스의 전사 길드 가입 후 계급이 영어 `Associate` 대신
`준회원`으로 나오는 것을 격리된 Windows 게임에서 확인했다.
이 확인은 모든 지역 퀘스트의 실게임 진행 검증을 뜻하지 않는다.

## 추가로 확인한 주제 ID 문제

8개 기본 주제 외에도 본편의 한국어 주제 ID와 지역 모드의 영문 응답 ID가 달랐다.
INFO 번호와 모든 화자·퀘스트 조건이 일치하는 본편 원문을 기준으로 대응표를 만들었다.
본편이 이미 합친 32개 동의어·복수형 묶음은 따로 검토했다. 모호한 일대다 대응은 허용하지 않는다.

기존 한국어 응답을 보호하고 지역 모드의 추가 응답만 한국어 주제로 복사한다.
영문 DIAL/INFO, 스크립트, 조건과 기존 순서는 유지한다.
동의어 주제 사이에 같은 INFO 번호의 서로 다른 응답이 있으면 빌드를 중단한다.

MRK의 지역 표기를 유지하면서 영문 ID와 한국어 ID의 대응을 TOP에 명시한다.
주제 학습 시 이 대응을 사용하고, 대화·일지 표시는 알고 있는 한국어 주제를 우선한다.
영문 주제만 알고 있는 저장 상태는 기존 영문 주제로 연결할 수 있다.
이미 한국어인 ID는 일반 TOP 구문으로 재해석하지 않는다.

Rebirth 지역 패키지는 TOP/MRK 파일명이 교체 ESM과 달라 로드되지 않았다.
이름을 교체 ESM과 맞추고, 같은 지역의 CEL/JRN을 복사한다.
원래 지역의 주제와 셀 대응이 교체 ESM에 유지되는지 확인하며 ESM 바이트는 이 단계에서 바꾸지 않는다.
일반 Cyr/Sky와 Rebirth 교체 ESM을 동시에 로드하지 않는다.

## 검증과 재현

`build_reviewed_regional_fixes.py`는 공개된 원본 ZIP의 SHA를 확인한 뒤
#66 기본 주제 복구, 검수된 표시 필드, 추가 공통 주제, Rebirth 파일명과 TOP 대응을 순서대로 재생한다.
각 단계는 원래 레코드·필드·ZIP 멤버를 비교하며 공개 저장소에는 원문 전체를 넣지 않는다.

Windows MSVC로 실제 KeywordSearch와 Translation::Storage를 컴파일했다.
개별 테스트는 한국어 주제 우선순위, 지역 표기, 영문 주제만 아는 저장 상태,
기존 일지·토픽 경계를 확인한다. 0.51.0 원본에 0001–0017 패치를 적용하는 검사도 통과했다.
전체 Windows 엔진 빌드와 통합 후보의 최종 실게임 검증은 후속 결과에 기록한다.
Ubuntu 엔진 빌드는 이 작업의 검증 요구 사항에 포함하지 않는다.
