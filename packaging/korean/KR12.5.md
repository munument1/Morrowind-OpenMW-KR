# OpenMW 한국어 KR12.5 — 잘못된 명시 토픽 링크 교정

2026-11-02. KR12.4의 누적 Windows 통합판입니다.

- 대사 29개에서 문맥과 무관한 명시 링크 태그 31개 제거: 신체 부위 ‘입’/‘입니다’ → 대변인, ‘자신의’ → 신앙, ‘자네·자격·가입하고자’ → 외지인, ‘법정의’ → 정의 연결.
- 한국어 표시 문자열, 퀘스트 조건, 결과 스크립트와 다른 ESP 필드는 보존했습니다.
- Windows 엔진은 검증된 KR12.4의 OpenMW 0.51.0 + 한국어 0001–0016 실행 파일을 그대로 사용합니다. 엔진 재빌드가 필요한 변경은 없습니다.
- 원본 ZIP/ESP 해시, 전체 레코드 대조, 비대상 ZIP 멤버 바이트 보존, CRC 및 중복 INFO ID 회귀 검증 통과. 실게임 플레이 검증은 수행하지 않았습니다.
- 압축을 풀고 기존 Install-Korean.bat으로 설치하세요. 별도 이슈 전용 패치가 아닌 전체 설치 패키지입니다.
- Android는 같은 ESP를 담은 데이터 ZIP을 별도 게시합니다. 새 APK는 포함하지 않으며, 기존 APK를 유지합니다.
