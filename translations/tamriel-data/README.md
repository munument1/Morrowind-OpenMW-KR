# Tamriel Data 한국어 번역 데이터

현재 배포 구성은 [같은 이름 ESM 교체 + CEL/TOP/MRK/JRN](../openmw-kr/README.md)입니다. 아래 데이터와 본문 검수 상태는 보존하고, 위 보조 파일을 함께 쓰는 빌드 도구를 추가했습니다.

Tamriel Data 26.08 (HD)의 영어·한국어 대조 데이터와 원문 위치, 검수 상태, 대상별 수정 기록입니다. 모드 ESM 및 설치 ZIP은 GitHub에 게시하지 않습니다. 모드 릴리스는 Nexus Mods에서만 진행합니다.

- [대조 데이터](26.08/Tamriel_Data.en_ko.jsonl.gz): 26,498개 행. `applied`가 참인 25,788개 필드만 테스트본에 반영합니다. 보류 행의 `ko`는 영어 원문이며, `candidate_ko`가 있으면 적용되지 않은 후보입니다.
- [버전·해시·검사 결과](26.08/manifest.json), [96개 수정 내역](26.08/repair_96_notes.json)

남은 책 722개 중 662개 번역 초안을 반영하고 60개 내부 문서/그림·빈 문서는 원문 보존합니다. 722개 모두 `NOT_REVIEWED`입니다. 이번 96개는 서식·변수·누락 중심의 보정이며 전체 문장 검수 완료로 올리지 않았습니다. 가상언어 두 책은 제목만 번역하고 본문은 원문 유지, 『진짜 바렌지아』 2권은 기존 모로윈드 순화판을 재사용한 판본 차이가 있습니다.

```sh
python translations/tamriel-data/build.py --check-only
python translations/tamriel-data/build.py --source "원본/Tamriel_Data.esm" --output "새출력/Tamriel_Data.esm"
```

원본 버전·위치·해시·태그·변수·링크와 출력 해시를 확인하며, 원본과 기존 출력 파일을 덮어쓰지 않습니다. 미검수 후보는 검증된 번역으로 간주하지 않습니다.

순화판을 쓰는 『진짜 바렌지아』 2권의 다른 판본 영어는 `en: null`로 두고 원본 버전·위치·해시 및 서식·변수 제약으로 검증합니다. 한국어는 기존 모로윈드 순화판입니다. 다른 행과 판본 차이를 혼동하지 않도록 표시합니다.

현재 재현 대상은 원본과 **같은 이름의 번역 ESM 복사본**입니다. 별도 번역 ESP/OMWADDON 방식이 아니며, `CELL.NAME`은 원문 보존, 모드별 `.cel/.top/.mrk/.jrn` 보조 파일은 아직 포함하지 않았습니다. 지역 표시명 및 토픽 보조 파일을 갖춘 최종 OpenMW 배포 구성은 별도 점검이 필요합니다. 원본 필수 자산이 필요하며 게임 적용·실행 검증은 하지 않았습니다.
