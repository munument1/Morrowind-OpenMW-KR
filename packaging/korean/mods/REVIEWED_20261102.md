## 검증과 한계

- 정확한 플러그인·레코드 유형·DIAL/INFO ID·필드 위치·원본 바이트 SHA를 모두 고정한다. INFO ID만으로 수정하지 않는다.
- 모든 레코드·서브레코드를 전후 대조한다. FNAM/선택 INFO.NAME 외 필드, 스크립트, 퀘스트 조건은 변경하지 않는다.
- 수정 대사의 표시 문자열 및 명시 링크 대상 순서가 전후 동일한지, UTF-8 BOM/CRLF/첫 별칭 우선 동작을 포함해 확인한다.
- 기존 ZIP 멤버 전부의 보존 여부·변경 허용 목록과 ZIP CRC/SHA를 검사한다.
- 합성 회귀 2개 및 기존 Rebirth 9개/PFP 4개 검사를 수행한다.
- 일반 문장 전체의 번역 정확도나 실게임 퀘스트·클릭 검증 완료를 뜻하지 않는다.
- Nexus 게시 후 API 버전 재조회뿐 아니라 실제 CDN에서 새 파일을 재다운로드해 생성 ZIP SHA와 일치하는지 확인한다. 결과는 게시 워크플로의 NEXUS_MODS_PUBLICATION_VERIFICATION.json에 기록한다.
