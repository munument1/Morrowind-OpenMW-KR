# 모드 한국어 번역 데이터

GitHub는 번역 데이터·대조표·검수 상태와 재현 가능한 빌드 도구를 보관하는 곳입니다. 모드 바이너리와 설치 ZIP은 GitHub Releases에 게시하지 않습니다. 실제 릴리스는 Nexus Mods에서만 진행합니다. OpenMW 엔진 릴리스와 이 모드 배포 방침은 구분합니다.

- [Tamriel Data](tamriel-data/README.md)
- [Project Cyrodiil](cyr-main/README.md)
- [Skyrim: Home of the Nords](sky-main/README.md)

미검수 초안, AI 검수, 보류 및 실게임 검증 여부를 서로 구분합니다. 자동 구조 검사 통과를 문장 검수 완료로 표시하지 않습니다.
