# OpenMW 0.51.0 한국어판 KR13.1 — 이슈 #71 표시 수정 (배포 전 검증 초안)

**상태: RELEASE CANDIDATE / Windows CI·격리 실행 검증 완료 / 배포 전.** 이 문서는 Windows 0.51.0 + 한국어 런타임 패치 0001~0019 기준으로 작성했으며, 검증 결과와 범위는 `reports/2026-11-16_issue71_runtime_qa.md`를 따른다.

## 적용 대상과 수정 범위

- **Windows x64 OpenMW 실행 파일:** 지역 확장 모드 대화창의 영문 DIAL 내부 주제 ID 대신 MRK 한국어 표시명이나 선택적 DSP 표시 전용 별칭을 출력한다. 클릭·검색·퀘스트 조건·기존 저장 파일은 원래 DIAL ID를 유지한다. (#71)
- **일지 주제 목록과 주제별 페이지 제목:** 같은 번역 표시명을 사용하며, 한국어 주제는 원래 영어 ID가 아니라 한국어 표시명의 초성으로 색인한다. (#71)
- **야외 NPC 자동 인사 자막:** `@제국`과 숨김 패딩 바이트 `0x7F`가 HUD에 원문 그대로 출력되지 않게 음성 자막 표시 경로에서 처리한다. 실제 INFO 대사·음성·게임 기록은 변경하지 않는다. (#71)
- **Tamriel Rebuilt 26.11.2:** `TR_Mainland.dsp`에 `Bloodstone Pilgrimage`, `Bloodstone Shrine`, `local area`, `retribution`, `go free`, `garyx rubber`의 한국어 제목을 추가한다. ESM/ESP 자체는 기존 검증본을 바꾸지 않는다.

## 언어 데이터 감사와 미해결 범위

기존 지역 모드 ESM의 영어 DIAL ID는 호환성 때문에 의도적으로 유지한다. 하지만 MRK/DSP 한국어 표시명이 없는 주제는 이번 엔진 패치 뒤에도 영어로 보일 수 있다. 실제 KR13 지역 ZIP의 정적 감사에서 TR_Mainland에 영어 ID 3,313개, 자체 MRK 755개, 교차모드 MRK 151개, 새 DSP 4개가 확인되었고, **2,403개는 아직 표시명 매핑이 없다.** 이 숫자는 NPC에게 실제로 표시되는 미번역 대화의 수가 아니며, 조건부 주제·고유명사를 포함한다. 기존 용어집·TOP 역방향·장비 이름에서 후보가 발견되더라도 의미 검수 없이 자동으로 DSP에 넣지 않는다. 나머지 모드의 매핑 상태 및 상세한 근거는 별도 감사 보고서에서 관리한다.

이 문제는 **대화·일지 UI 표시 경로 버그의 해결**과 **지역 모드 자체의 번역 표시명 보강**을 구분해서 추적한다. 이번 버전이 모든 지역 모드 대화 주제의 번역 완료를 의미하지 않는다.

## 설치 및 호환

기존 KR13 Windows 전체 ZIP을 기반으로 새로운 OpenMW 실행 파일을 포함하는 **KR13.1 Full ZIP**을 설치한다. 지역 모드는 원본 26.11.2/26.08/26.09a 버전에 맞는 기존 덮어쓰기 패키지를 사용하고, TR_Mainland의 새 DSP가 포함된 패키지는 별도로 설치한다. Morrowind·Tribunal·Bloodmoon의 정품 파일이나 모드 원본 아트 리소스는 포함하지 않는다. 다른 버전 Rebirth용 Cyr/Sky 대체 ESM과 일반 Cyr/Sky ESM을 동시에 활성화하지 않는다.

Android APK는 Windows 빌드와 별개이다. 기존 Android 0.51.0-12 서명 APK에 KR13.1 엔진의 0018/0019 수정이 자동 반영되지는 않는다.
